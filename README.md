# GlassPaint Studio для iOS

Профессиональное приложение для рисования и редактирования графики в стиле Liquid Glass (жидкое стекло) на SwiftUI + PencilKit + Vision AI.

## Возможности

- **Инструменты рисования**: Перо, Карандаш, Маркер, Акварель, Ластик, Лассо на базе PencilKit с поддержкой Apple Pencil и жестов пальцами.
- **Работа с фото-слоями**: Импорт фото из медиатеки, перемещение, масштабирование (pinch-to-zoom), вращение двумя пальцами.
- **Удаление фона на лету (Vision AI)**: Автоматическое вырезание объекта с фотографии в один тап с прозрачным фоном.
- **Студия цветокоррекции и фильтров**: Настройка яркости, контраста, насыщенности, резкости, размытия, а также пресеты (Нуар, Сепия, Винтаж, Негатив и др.).
- **Менеджер слоёв**: Иерархия слоёв холста, скрытие/отображение, блокировка, дублирование, удаление, регулировка непрозрачности.
- **Дизайн в стиле Liquid Glass**: Парящие панели из матового жидкого стекла с размытием (.ultraThinMaterial), бликами и отсутствием смайликов в интерфейсе (только аккуратные SF Symbols).
- **Экспорт**: Экспорт готовой работы в высоком разрешении через системное меню «Поделиться».

## Сборка IPA

Проект собирается автоматически через GitHub Actions на macOS раннере.
